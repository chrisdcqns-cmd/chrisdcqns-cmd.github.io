# Cross-training (CA5) — notes de l'appli

- `index.html` autonome, couleur `#4D7C0F`, code d'appli `ct`. Charte commune : `../CLAUDE.md`.
- Bibliothèque : 20 exercices sans matériel × 3 niveaux (`BIBLIO_DEFAUT`) ; fiches modifiables en mode enseignant, publiées dans `bibliotheque.json` du dossier Drive.
- Vidéos : dossier Drive réglé par l'enseignant (propriété `CT_DOSSIER` du script commun). Noms reconnus : `N1.mp4`, `N2-2.mp4`, `N2_3.mp4`, `N2b.mp4`, `N2 (2).mp4`, sous-dossier `N2/…` ; 3 vidéos max par niveau.
- Script commun (`../apps-script/Code.gs`) : `GET ?ct=biblio` (fiches + liste), `GET ?ct=video&id=` (base64, pour le hors ligne), `POST {key, ct:{dossier|partager|fiches}}`.
- Hors ligne : vidéos dans IndexedDB `ct_videos` (bouton « Télécharger » de la Bibliothèque) ; lecture locale sinon lecteur Drive.
- Thèmes (version du livret, améliorée) : Renforcement 60-70 % FCM (circuit, EMOM ; 12-15 rép.), Mental 70-80 % (AMRAP à allure imposée, For Time), Cardio 80-90 % (intervalles 30/30 ou 40/20, EMOM, E2MOM ; FC relevée en fin de bloc).
- Élève : classe (écran commun ; sans classe = bibliothèque seule) → groupe (solo / binôme / trinôme selon `cfg.groupes`) → Mon WOD → ▶ timer → résultat dans le carnet.
- Magasin synchronisé `ct.v1` (`EPSD.store`, préfixe `ct|`) : `cfg` (groupes, `ia` élèves, `iaProf`), `j|<classe>|<date>` leçon du jour (`mode` impose | forme | libre, consigne, thème / format / `params` imposés, `wod` imposé), `w|<id>` résultats (classe, noms du groupe, WOD, score, `cpt` Rep / No rep de l'observateur, RPE 0-10, FC, analyse).
- Matériel : champ `materiel` (PC, KB, MB, CORDE) ; 12 exercices avec matériel (`EXOS_MATERIEL`, 4 niveaux) ajoutés une seule fois par `completerFiches()` (liste `fiches.vus`, une fiche supprimée ne revient pas). Les niveaux vont jusqu'à 4 (vidéos N1.mp4 à N4.mp4).
- WOD types : `WODS` (16 WOD, matériel × thème), chargés dans `S.lecon` par `wodEnLecon`.
- FC : bulle ❤️ (âge et FC de repos en sessionStorage `ct_age`, `ct_fcrepos`), FCM Tanaka, zones % FCM (Karvonen si FC de repos), mesure du pouls 30 s × 2 (refusée sous 10 s).
- Affichage `ct_affichage` : auto | tel | tab (classe `tel` / `tab` sur `<html>`).
- WOD enregistrés (modèles) : locaux à la tablette (`ct_lecons`).
- Évaluation : `EPSE.store` (`EVCT`, grille CA5 AFL1 6+6, AFL2 4, AFL3 4) ; Bilans = carnets de la classe + bilan commun.
- Claude (script commun, `lecon_`) : `op:'ctwod'` (WOD proposé à l'enseignant, brouillon), `op:'ctconseil'` (conseils à l'élève, seulement si `cfg.ia`), `op:'grille'` (import Additio, commun à toutes les applis via eps-eval.js).
- Tablette partagée : `scinde.html` = 2 iframes `./?box=1` et `./?box=2`. `BOX` préfixe le sessionStorage (`SS`, clés `ct_bN_…`) et `lecon` / `lecons` en localStorage (`LSK`) ; bip plus grave pour la box 2.
- `?mode=ressource` (`RESS`) : onglets Exercices / WOD types / Zones et pouls (`vueFCtab`) / Grand chrono, sans écran classe ; FC en mémoire seulement (`MEMFC`).
- Athlète / coach : `S.duoNext` → `TM.duo` ; `roles()` = noms[0] athlète, noms[1] coach ; `coachHtml` / `majCoach`, PASER (`TM.paser`, `paserResume`), `TM.flip` (LS `flip`) ; résultat `res.duo {ath, coach, paser, rpeCoach}` ; `changerRole()` fait tourner les noms.
- Grand chrono : préréglages `CHRONOS` (tabata, i3030, i4020, ct6, ct8, emom, e2mom, amrap, ft), chronos perso de l'enseignant en LS `chronos` ; `lancerGC` / `tickGC` / `vueChrono` ; `chronoDeWod` pour un WOD type. Exercices : `c.ex` (liste de noms ; `S.gcForm.ex` texte, un par ligne, appliqué aux préréglages sans `ex`) → `ph.ex` par phase de travail (atelier s, ou à tour de rôle), `ph.liste` en AMRAP / For Time ; affichage : nom en grand (`.gc-exo`), bandeau `.gc-suiv` « Ensuite … puis … ».
- Chronos perso : type `seq` (« Étape par étape », `etapes [{ex, travail, repos}]`, `tours`, `recupTour` ; repos de la dernière étape remplacé par la récup entre tours) ; express `XP` (paires travail-repos) → `gcExpress()` (`S.gcForm.xp`, `xpN`), enregistrable dans LS `chronos` par l'enseignant.
