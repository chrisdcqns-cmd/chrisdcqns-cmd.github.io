# Acrosport EPS — notes pour Claude

> Lire d'abord la charte commune : `../CLAUDE.md` (barre, couleurs, écran « Choisis ta classe », accès enseignant caché, listes communes, PDF et auto-positionnement au format Danse/Volley).

Application web (PWA) d'acrosport pour tablettes, hébergée sur GitHub Pages depuis la branche `main` (racine).

- `index.html` : toute l'appli dans un seul fichier (HTML + CSS + JS). Les données des 176 figures (`const FIGS`) et les photos (`const IMGS`, images WebP en data URI) sont des lignes JSON très longues : modifier le code autour, pas ces lignes à la main.
- `v/` : vidéos d'origine du PowerPoint « AcroEPS niveau intermédiaire » (M. Avisse & Y. Tomaszower, Académie de Créteil). Ne pas recompresser, sauf pour un format illisible : toute vidéo doit être en H.264 (Chrome / Android ne lisent pas le MPEG-4 « Simple Profile » : seulement le son). Les 8 vidéos d'échauffement du Bonus concernées ont été converties en `v/mediaN-h264.mp4` (25/11/2026). Vérifier avec ffprobe toute nouvelle vidéo. Le bouton « Télécharger les vidéos » inclut celles du Bonus.
- `sw.js` : service worker (réseau d'abord pour la page → mises à jour automatiques ; vidéos servies depuis le cache `acro-videos-v1` si téléchargées). Changer `CORE` (acro-core-vN) si on ajoute des fichiers à `CORE_FILES`.
- `apps-script/Code.gs` : serveur Google Apps Script (Google Sheet) pour la sauvegarde en ligne. L'URL /exec se règle dans `API_DEFAULT` de `index.html` ou dans l'espace enseignant.
- Interface et textes en français ; utilisateurs : lycéens (classe EPS « 1GT », élèves de 1G1-1G4 et 1STMG) et leur enseignant d’EPS. Classes et listes d’élèves : onglets « Classes » et « Eleves » de la Google Sheet (jamais de noms d’élèves dans ce dépôt public).
- Espace enseignant (⚙) : mot de passe enseignant du script, saisi avec le pavé `epsPin()` (copie de celui d'`eps-home.js` : pas de clavier du système, rien d'affiché, touche ABC), vérifié en ligne (action teacherCheck) ; empreinte locale pour l'accès hors connexion. Code `eps` seulement si aucun script n'est configuré. Pour limiter le nombre de pyramides d'une leçon : lien `#pyramides-N`.
- Modèle d'enchaînement : `G.current.slots[i] = {parts:[{fig, roles}]}` — une figure peut réunir plusieurs pyramides simultanées (comptent pour 1 figure). Toujours passer par `partsOf(slot)` (gère l'ancien format `{fig, roles}`).
- Liaisons : uniquement sur le tapis (`current.dojo.items`, `kind:"el"`, `pic` = élément gymnique de `BONUS.trans`). Les anciennes zones de texte `mats` sont converties en étiquettes.
- Synchro : jeton de groupe (`token`, jamais le mot de passe en stockage local), numéro de version `rev` + fusion en cas de conflit (`mergeGroups`), envoi auto du brouillon (`autoDirty`, 40 s). Leçon du jour par classe : `teacherSetLesson` → colonne `pyramides` de l'onglet Classes ; `lessonN(classe)`.
- Observation : critères `CRIT` (statique) / `CRIT_DYN` (dynamique), clés de notes `f{figure}p{pyramide}|rôle|critère` (anciennes clés `f{i}|…` encore lues).
- `const BONUS` (échauffement + vidéos `v/media1..17.mp4`, éléments gymniques A–D, prises de mains) est généré au build comme `FIGS`.
- Bouton « Accueil » commun : `<script src="../eps-home.js" defer>` (page d'accueil `/eps-autonomie-numerique/` qui regroupe Acrosport, Escalade, OrienRun et Relais Vitesse dans un seul APK).
- Acrosport fait partie du dépôt `chrisdcqns-cmd.github.io` (dossier `eps-autonomie-numerique/acrosport/`) ; l'ancien dépôt `chrisdcqns-cmd/acrosport` ne contient plus qu'une page de redirection. Le service worker relit aussi les vidéos téléchargées à l'ancienne adresse `/acrosport/v/`.
- Leçons enregistrées : une seule par jour (`oneADay`, `dayOf`) — `saveProgress` remplace l'enregistrement du jour, `mergeGroups` et le chargement regroupent aussi par jour. Vocabulaire : « leçon », jamais « séance ».
- Curseur de défilement `#scrollRail` (fin du script) : visible quand un tapis `.dojo` est à l'écran (hors plein écran), pour faire défiler la page sans toucher le tapis.
- Logo : `icon-192.png` / `icon-512.png` (pyramide à trois, fond bleu, voltigeur jaune), aussi utilisé par la page d'accueil commune.
- Bilans de la classe : espace enseignant → En ligne → classe + date → « 🗜️ Bilans de la classe (.zip) » (`zipBilans`, `acroPdf`, `EPDF`) : lit en ligne les groupes (`teacherList`/`teacherLoad`), la liste (`listStudents`) et les observations du jour ; un PDF par élève (groupe, enchaînement du jour et rôle de l'élève, liaisons, schéma du tapis `dojoJpeg` en JPEG via `doc.image`, observations reçues).
- Ceintures (onglet `🥋 Ceintures` = `data-tab="path"`, `renderPath`) : par position `PATH_T` (horizontale, équerre, redressée, ATR), difficultés A → D. Niveau validé = `beltNeed()` observations réussies (`EPSP` id `ceintureObs`, défaut 2) d'une pyramide de la position et de ce niveau ou plus (`beltCalc(obs, ov)`, pur, aussi utilisé par l'enseignant), ou validation de l'enseignant `G.progress.ov['t|A']` = true/false, horodatée `G.progress.ovAt` (la plus récente gagne dans `mergeGroups` ; renvoyée par `myObservations` → relue par `loadObsAbout`). Valider un niveau ouvre le suivant (`openLv(t)`, `figLocked(f)`, `lockMsg`) ; dynamiques toujours ouvertes ; groupe ouvert par l'enseignant jamais bloqué. Couleurs `BELT_C`, noms `EPSP` id `ceintures` (blanche, jaune, orange, verte, bleue ; noire = D partout). Résumé `G.progress.summary = {v:2, tops, black}`. Pyramide réussie = `partValid` (≥ 3 critères notés, aucun ✗, ≥ 75 % ✓, maintien ✓, pas d'erreur de sécurité sur la figure).
- Réglages de classe (onglet Classes, colonne `reglages` JSON) : `theme` (thématique du jour → filtre par défaut + bandeau), `progressif` (= ceintures activées), `obsGrid`, `steps`, `seq`, `rot`. Script : `teacherSetClassSettings`, `teacherBelts` (validations de chaque groupe + observations complètes de la classe) ; `listClasses` renvoie `reglages`.
- Mode enseignant partagé : `openProf` sans code si actif ; le mot de passe du script est retenu sur la tablette (`localStorage['acro.tpw']`) après la 1re saisie. Curseur de défilement fin (30 px).
- Ceintures visibles des élèves seulement si activées pour la classe (`beltsActive`) ; sinon masquées (`html.noBelts`) et tout est ouvert, sauf aperçu enseignant (`acro.beltsPreview`, case `#pPrev`). Enseignant : `beltsClass()` (🥋 Ceintures de la classe : activer, tableau groupes × positions × A–D, une case = valider / refuser / automatique → `teacherLoad`/`teacherSave`).
- Vidéothèque (`filterBar`) : 4 tuiles de position alignées (photo `POS_IMG`, nombre de figures, niveaux ouverts), pas de thématiques dynamiques (sans rotation, rotations transversale / longitudinale : jamais affichées, demande de l'enseignant ; les figures dynamiques sont réunies sous « Figures dynamiques », par formation, et leur fiche dit « Figure dynamique »), puis formation et difficulté (🔒 sur les niveaux fermés) ; titres de la grille dans l'ordre `PATH_T`.
- Fiabilité de l'enregistrement : `G.curAt` = date de la dernière vraie modification de l'enchaînement (`curSig`/`curSnap` dans `persist`), seule base de comparaison entre tablettes (`mergeGroups`, connexion) — ne jamais comparer `editedAt` (change à chaque `persist`). `autoDirty` seulement si l'enchaînement ou la progression change. Écriture locale par `saveGroups()` (allège puis retire les groupes déjà en ligne si la mémoire est pleine) — ne pas appeler `store.set(K_GROUPS…)` directement.
- File des observations : `getBox`/`setBox` (`{gid, obs, hold}`), identifiants résolus à l'envoi (`credFor`) ; une observation n'est retirée que si le serveur confirme ; mot de passe changé / groupe introuvable → `hold` jusqu'à la reconnexion du groupe (badge « 🔑 Reconnecte le groupe »).
- Parcours de leçon (élèves) : barre `#stepBar` (`renderSteps`, `stepDone`, `stepMark`), étapes `STEP_K` warm/figs/rep/obs/save, intitulés `EPSP` id `etapes` (fixed 5), état du jour `G.steps={day,v}` ; figs/obs/save calculés (figures choisies, `obsLog`, `sessions` du jour). Masquable par classe : réglage `steps:false`.
- Mode répétition `openRepeat(i)` (`#repMode`, plein écran, vidéo, rôles, minuteur de tenue `EPSP` id `tenue`).
- Mot de passe oublié (`forgotPw`, accueil) et 🔑 du tableau de bord : `resetGroupPw` → `teacherSetPassword` avec un code à 4 chiffres ; `needTpw()` demande le mot de passe du script si la tablette ne l'a pas.
- Observation : grille essentielle `ESS`/`ESS_DYN` (doit garder `maintien` pour `partValid`), `obsEss` lu par `critColumn` (jamais en lecture seule) ; choix élève `o.grid`, réglage de classe `obsGrid` = auto (essentielle tant que le groupe n'a enregistré aucune observation) | ess | full.
- Rotation d'observation : réglage de classe `rot={day, pairs:{norm(observateur): observé}}` (`makeRotation`, boucle aléatoire), lue par `rotTarget()` ; l'onglet Observation relit les réglages (`refreshClasses`) et charge le groupe cible une fois par brouillon (`o.rotTried`).
- Réglages de classe : toujours passer par `saveClassSettings(classe, patch)` (fusion), jamais `teacherSetClassSettings` avec un objet partiel (sinon rotation, grille, étapes, dates `seq` effacées).
- Enseignant : `seqWizard()` (🚀 Démarrer une séquence), `lessonDashboard()` (📊, action script `teacherDashboard` : groupes avec dernière leçon `derniere`, `slots`, observations de la classe ; actualisé 30 s), `fixNames()` (🔗, `teacherLoad` → `renameIn` membres + rôles → `teacherSave` avec `baseRev`). Cartes dans les onglets Séquence et Classe d'`EPST.init`, et boutons en tête de l'espace enseignant.

- Trame de séquence `trame-1gt.js` (`EPS_TRAMES`, id `acro-1gt-8`) : 8 leçons pour la 1re générale (horizontale → équerre → redressée → ATR → composition → répétition générale → évaluation de fin de séquence), sans situations ; bouton « 📥 Trame proposée » des fiches de leçon communes. Cadre : programme LGT 2019 CA3, référentiel CCF (BO n° 9 du 26-2-2026, référentiels inchangés) ; en 1re pas de CCF (terminale).
