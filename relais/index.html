Éléments à saisir pendant la course

Coche ce que les élèves saisiront dans « Enregistrer les courses ». Un élément décoché est enregistré « non renseigné » et n'apparaît pas pour les élèves. Les coureurs et la vitesse cible sont toujours présents.

Mode de saisie

Les élèves saisissent directement leur vitesse, ou le temps chronométré sur une distance (la vitesse est alors calculée).

Reformer les groupes de cette leçon

Les courses sont rangées dans les groupes actuels de la classe : une course va dans le groupe qui contient ses deux coureurs (sinon celui du coureur 1). Pour changer la composition des groupes, modifie-les d'abord dans « Groupes ».

Préparer une leçon

Choisis la date de la leçon à préparer (groupes, éléments à saisir…). Le jour venu, elle s'ouvrira comme leçon du jour.

Sauvegarde des données

Le fichier de sauvegarde contient toutes les classes, élèves, vitesses, groupes, leçons et courses de cette tablette. Il sert à garder une copie ou à transférer les données vers un autre appareil ou une autre version de l'application (par exemple de la version Claude vers l'APK). Il contient les noms des élèves : garde-le pour toi.

Restaurer ajoute les données du fichier à celles de la tablette : rien n'est supprimé, et une course déjà présente n'est pas dupliquée.

Envoyer les courses vers Google Sheets

Chaque course enregistrée est ajoutée à ta feuille Google. Les noms des élèves ne sont jamais envoyés : seulement un code anonyme (ou le prénom et l'initiale, si tu le choisis). La correspondance code ↔ élève reste sur la tablette, dans l'export Excel (feuille « Vitesses »).
